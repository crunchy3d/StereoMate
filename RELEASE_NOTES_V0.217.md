**StereoMate V0.217 is the first public version.** StereoMate aligns and finishes stereoscopic (3D) photos and videos: automatic alignment, depth control, crop, floating window, colour matching, Compose, video clips, time-lapses, slide shows and a second screen. See the [README](https://github.com/crunchy3d/StereoMate#readme) for everything it does.

### Which file do I need?
- **Windows:** `StereoMate_0.217.0_x64-setup.exe` (installer), or `StereoMate_0.217.0_portable.exe` (no installation). The `.msi` is an alternative installer.
- **Linux:** `StereoMate_0.217.0_amd64.AppImage` (make it executable and start it) or the `.deb` package.
- **Web version (Chrome / Edge):** `StereoMate_web_0.217.0.zip`. Unpack it and open `StereoMate.html`; keep `opencv.js` in the same folder. It has fewer capabilities than the desktop program. You can also [try it online](https://crunchy3d.github.io/StereoMate/).

Windows may show “Windows protected your PC” because the program is not code-signed: click **More info → Run anyway**.

### New in this version
- Video clips and time-lapses in **Compose**, rendered as a video (start time per clip, hold the last frame or loop, sound from a chosen clip).
- **Time-lapses** as one entry: Open time-lapse…, Group as time-lapse…; rendered at any frame rate.
- Crop X / Y relative to the automatic crop; fixed Play / Pause button and **Enter** = Play / Pause.

Questions and problems: please open an [Issue](https://github.com/crunchy3d/StereoMate/issues).
